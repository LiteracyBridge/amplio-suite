# Windows Installer

Make a Windows Installer using [NSIS](https://nsis.sourceforge.io/Main_Page)

## Steps

* Download `acm.jar` and `lib/` dir from `Dropbox:LB-software/ACM-install/ACM/software`
* Dowload Java 8 and rename as `jre_setup.exe`
* Run NSIS
